# RPM SMART 2026

Aplikasi penyusun Rencana Pembelajaran Mendalam untuk guru SD.

## Prototipe awal
Fokus pengembangan: Pendidikan Pancasila kelas III, materi Aku Patuh Aturan.

Aplikasi awal akan menyediakan generator draf RPM, editor, LKPD, rubrik, penyimpanan lokal, dan ekspor Word/PDF.
